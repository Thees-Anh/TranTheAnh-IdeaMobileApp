## 2026-11-12 - P1: on-time reminders, Focus countdown, offline viewing, dark mode

- Quest reminders: migration `20261112003200_reminder_schedule.sql` adds read-only
  `reminder_schedule()` (pending deadlines in the next 48h). The device arms an
  AlarmManager alarm for the next reminder (2h before a deadline, 08:00–22:59,
  daily idea 09:00); exact when the user allows it, otherwise Android may defer a
  few minutes. When the alarm fires it syncs live, or offline posts quest
  reminders from the cached schedule. Alarms are restored after reboot, app
  update and time/zone changes. A later deadline on the same day is no longer
  suppressed by an earlier reminder.
- Focus: the 5-second "come back" nudge is replaced by an ongoing countdown
  notification while Focus runs in the background and a "Focus finished" alert
  (new high-importance channel) from an alarm at the session end, also when the
  app process was closed. Both still require the in-app notification consent.
- Offline viewing: last confirmed account, pet + wallet and quest list are
  cached app-private and shown read-only with an "Offline · showing data from
  HH:mm" banner; launching offline with an expired token enters from the cache
  after 5s. Every change still needs the server; data refreshes automatically
  when the connection returns. The startup Focus check no longer blocks the app
  when it fails offline.
- Dark mode: warm night palette, Appearance setting (Match system/Light/Dark),
  night launch window, system bar icons follow the choice, default text colour
  follows the theme.
- Bugs: Focus presence/notifications use the current pet's name instead of
  "Mochi"; the widget hint source string is English (it was already translated
  at display time, so this was a consistency fix, not a visible bug).
- Without exact-alarm access, reminders re-arm in "prepare" hops that always
  wake before the reminder, narrowing Android's up-to-1h inexact window to ~10 min.
- Verified on the emulator against the hosted project: alarm-fired quest
  reminder, Focus countdown and "Focus finished" alert (see TEST_REPORT.md).

## 2026-11-11 - Fix late pet collection overwriting care state
